# 色差Lab（ColorLab）安卓工程

## 功能
- 上传图片 / App 内相机拍摄
- 拍摄时：点击白卡/灰卡 → 测光+白平衡 → 锁定 AE/AWB；锁定后点击画面可重新对焦（不解除锁定）
- 拍完自动以白卡位置做软件白平衡校正；上传的图片也可手动「白卡校正」
- 取点器：按住出现放大镜+十字准星，松手落点；第一个点为 STD，之后为 T1、T2…
- 点位：拖动微调、长按删除、锁定、设为 STD、撤销/重做、双指缩放
- 取样大小滑杆（圆形/方形），显示像素数
- 悬浮 Lab 对比表格：可拖动、可折叠成小球、点击行高亮对应点
- ΔE*ab = √(ΔL*² + Δa*² + Δb*²)，容差（合格/临界/不合格）在设置页调整
- 取样区域标准差 σ，三档梯度（均匀/轻微不均/不均匀），阈值可调
- 底部金刚键：测量 / 描述 / 设置
- 描述页：每个样品的色块对比、数值、判定、自动生成的偏色说明、a*b* 色度图，可复制说明与 CSV

## 方式一：GitHub 自动编译（无需安装任何开发工具）
1. 新建一个 GitHub 仓库，把本文件夹的全部内容上传（包括 `.github` 隐藏文件夹）
2. 打开仓库的 **Actions** 页，等待 “Build APK” 运行完成（约 3–5 分钟）
3. 点开该次运行，在底部 **Artifacts** 下载 `ColorLab-apk`，解压得到 `ColorLab-v1.0.0.apk`
4. 传到手机安装（需允许“安装未知来源应用”）

## 方式二：Android Studio
用 Android Studio 打开本文件夹 → 等待 Gradle 同步 → Build ▸ Build APK(s)。

## 修改界面/算法
所有界面和计算都在 `app/src/main/assets/www/index.html`，改完重新编译即可。
该文件也可以直接用电脑浏览器打开预览（相机功能需在手机上测试）。
